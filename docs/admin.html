Шаг 1 · Токен GitHub

Сайт статический, поэтому список сохраняется прямо в репозиторий через GitHub API. Нужен токен с правом «Contents: Read and write» только для этого репозитория.

Как создать токен (один раз, ~минута)
  1. GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token
  2. Repository access → Only select repositories → Zaytsevandrei/archero2Dashboard
  3. Permissions → Repository permissions → Contents → Read and write
  4. Скопируй токен (github_pat_…), вставь ниже — он останется только в этом браузере

Допущенные игроки

Скриншоты бота принимают только админы и игроки из этого списка (можно альбомом из нескольких картинок — бот запишет всех игроков со скрина). Клан используется для записей, у которых клан игрока определить не удалось. Бот подхватывает изменения в течение ~10 минут.
