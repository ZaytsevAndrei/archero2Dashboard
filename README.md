# 🏹 Archero 2 — Календарь урона (кланы Unity и Unity2)

Сайт с календарём урона по событию «Вторжение монстров». Допущенные админом
игроки отправляют скриншоты рейтинга в Telegram-бота
[@Archero2Unity_bot](https://t.me/Archero2Unity_bot) — данные автоматически
попадают на сайт. Две вкладки: «Сегодня» (урон за сегодня и рейтинг месяца) и
«Календарь» (месяц с уроном по кланам разными цветами: Unity — золотой, Unity2 —
фиолетовый). Языки сайта — русский, английский и вьетнамский (автоматически по
браузеру, переключатель в шапке); язык бота — по языку Telegram-клиента (`/lang`).

## Как это работает

```
Допущенный игрок → @Archero2Unity_bot (скрин или альбом скринов рейтинга)
      → VPS (Debian): scripts/poll.mjs в режиме BOT_LOOP=1 — long polling,
        ответы за секунды; OCR скриншотов (tesseract.js): записываются ВСЕ
        игроки, видные на скрине (ник канонизируется по известным)
      → бот сам коммитит docs/data.json в этот репозиторий (deploy key)
      → GitHub Pages показывает сайт

Админ (Dragon) → docs/admin.html на сайте: список допущенных игроков
      → правки сохраняются в docs/config.json через GitHub API (токен
        в браузере админа), бот подтягивает их ~раз в 10 минут
```

Сайт — на GitHub Pages (бесплатно, CDN, не зависит от VPS). VPS отвечает только
за бота: systemd-сервис `archero-bot` (перезапуск автоматически, после ребута тоже).
GitHub Actions из `poll.yml` — страховка раз в сутки, если VPS молчит (очередь
Telegram живёт 24 ч). Деплой на новый VPS: `scripts/setup-vps.md`.

## Доступ: кто может слать скрины

Скриншоты и команды бота принимаются **только от админов и допущенных игроков**
из `docs/config.json` (админ правит список на странице `/admin.html` сайта).
Остальным бот отвечает «доступ закрыт», а админам один раз в сутки приходит
уведомление с именем и Telegram ID постучавшегося — по нему игрока можно добавить.

Схема `docs/config.json`:

```jsonc
{
  "admins": ["176147068"],              // уведомления + полный доступ; владелец — всегда
  "submitters": [                       // кому бот принимает скрины
    { "tgId": "176147068", "nick": "Dragon", "clan": "unity",
      "tgUsername": "katoteshikuza", "added": "2026-10-07" }
  ]
}
```

### Админка на сайте (`/admin.html`)

Сайт статический, поэтому страница сохраняет список через **GitHub Contents API**:
один раз создаётся fine-grained токен (Settings → Developer settings →
Fine-grained tokens → только репозиторий `ZaytsevAndrei/archero2Dashboard` →
Permissions → Contents: *Read and write*), вставляется на странице и хранится
в localStorage браузера админа. Страница также показывает всех известных боту
игроков с их Telegram ID — добавление в один клик. Бот подхватывает изменения
`config.json` после каждого своего пуша и раз в ~10 минут (`git pull --rebase`).

## Бот — команды

| Команда | Что делает |
|---|---|
| `/start` | приветствие + запрос игрового ника, затем клана (Unity / Unity2) |
| `/nick НовыйНик` | сменить ник |
| `/clan` | указать или сменить клан |
| `/lang` | язык бота (авто — по языку клиента Telegram: русский/english) |
| `/undo` | удалить последнюю запись или всю последнюю отправку-альбом |
| `/stats` | мои записи за 7 дней (включая урон, записанный с чужих альбомов) |
| `/help` | справка |

Отчёт об уроне: отправить **скриншот рейтинга** — бот скачивает его (доказательство
сохраняется), распознаёт через OCR (`scripts/ocr.mjs`) **весь список рейтинга на
скрине** и записывает урон каждого найденного игрока; ник канонизируется нечётким
сравнением с известными никами (игроки, игроки из списка, история записей), клан —
игрока, иначе клан отправителя. Альбом из нескольких картинок обрабатывается одной
пачкой с одним итоговым ответом; если скрин не читается — бот пробует строку ника
самого отправителя, затем просит скрин получше. Ручной ввод числом отключён.
Повторная отправка тем же днём **перезаписывает** значение игрока. Игровой день
длится с 03:00 до 03:00 по Москве: урон, присланный с 00:00 до 02:59, записывается
за предыдущий календарный день.

Работает и в общем чате гильдии (скрины допущенных игроков; чужие молча
игнорируются). Данные языков tesseract (eng+rus, офлайн) лежат в `scripts/tessdata/`.
Любая правка OCR — только с чистым прогоном `node scripts/regression-ocr.mjs`
(два прохода: строка владельца через `ocrOwnRow` и весь список через `ocrBoard`).

## Деплой (один раз, ~5 минут)

1. **Репозиторий на GitHub**: создать **публичный** репозиторий и запушить:
   ```
   git remote add origin https://github.com/<user>/archero2Dashboard.git
   git push -u origin main
   ```
   (в этом проекте remote уже указывает на `ZaytsevAndrei/archero2Dashboard`)

2. **Секрет токена** (рекомендуется): Settings → Secrets and variables → Actions →
   *New repository secret* → имя `TG_BOT_TOKEN`, значение — токен бота.
   Пока секрета нет, работает встроенный запутанный fallback-токен (только для MVP).

3. **Первый запуск**: вкладка Actions → *Telegram poll & publish* → *Run workflow*.
   Workflow сам включит GitHub Pages (ветка `main`, папка `/docs`).

4. **Сайт**: `https://<user>.github.io/archero2Dashboard/` — появится через 1–3 минуты.

Если Pages не включился автоматически: Settings → Pages → Source: *Deploy from a branch* →
`main` / `/docs`.

## Сброс демо-данных

В `docs/data.json` лежат демо-записи (`"demo": true`) для примера. На сайте их можно
скрыть кнопкой «Скрыть демо». Чтобы удалить совсем: убрать их из массива `entries`
и закоммитить.

## Структура

```
docs/            сайт (GitHub Pages): index.html, app.js, style.css, data.json, proofs/
docs/admin.html  админка допущенных игроков (admin.js, правит docs/config.json через GitHub API)
docs/config.json список админов и допущенных отправителей скринов (правится админкой)
scripts/poll.mjs логика бота: опрос Telegram, доступ, альбомы, OCR, запись данных
.github/workflows/poll.yml   расписание + автокоммит + включение Pages
```

## Замечания для продакшена

- Токен в open-source: задайте секрет `TG_BOT_TOKEN` и перевыпустите токен у @BotFather
  (текущий был опубликован в переписке).
- `getUpdates` нельзя использовать одновременно с webhook — скрипт снимает webhook при
  конфликте.
- Лимит файла для пруфа — 20 МБ (ограничение Bot API).
- Видеопруфы хранятся как один JPEG-кадр, чтобы репозиторий не пух.
- Скриншоты-пруфы хранятся **7 дней** (включительно): с 8-го дня файл и ссылка в
  `data.json` удаляются автоматически (записи урона остаются). Чистка запускается при
  старте бота и раз в сутки; ручной запуск: `PRUNE_ONLY=1 node scripts/poll.mjs`.
