# 🏹 Archero 2 — Календарь урона (гильдия Unity)

Сайт с календарём урона по событию «Вторжение монстров». Игроки отправляют видео
рейтинга и урон в Telegram-бота [@Archero2Unity_bot](https://t.me/Archero2Unity_bot) —
данные автоматически попадают на сайт.

## Как это работает

```
Игрок → @Archero2Unity_bot (скриншот рейтинга)
      → VPS (Debian): scripts/poll.mjs в режиме BOT_LOOP=1 — long polling,
        ответы за секунды; OCR скриншотов (tesseract.js)
      → бот сам коммитит docs/data.json в этот репозиторий (deploy key)
      → GitHub Pages показывает сайт
```

Сайт — на GitHub Pages (бесплатно, CDN, не зависит от VPS). VPS отвечает только
за бота: systemd-сервис `archero-bot` (перезапуск автоматически, после ребута тоже).
GitHub Actions из `poll.yml` — страховка раз в сутки, если VPS молчит (очередь
Telegram живёт 24 ч). Деплой на новый VPS: `scripts/setup-vps.md`.

## Бот — команды

| Команда | Что делает |
|---|---|
| `/start` | приветствие + запрос игрового ника |
| `/nick НовыйНик` | сменить ник |
| `/undo` | удалить свою последнюю запись |
| `/stats` | мои записи за 7 дней |
| `/help` | справка |

Отчёт об уроне: отправить **скриншот рейтинга** — бот скачивает его (доказательство
сохраняется), распознаёт через OCR (tesseract.js, `scripts/ocr.mjs`) строку с твоим ником
и предлагает подтвердить урон кнопкой «✅ Записать». Ручной ввод числом отключён:
не распознал — бот попросит прислать скрин получше. Повторная отправка тем же
днём **перезаписывает** значение. Дата записи — по московскому времени.

Работает и в общем чате гильдии (игроки с ником Telegram = игровой ник
регистрируются автоматически). Данные языков tesseract (eng+rus, офлайн) лежат
в `scripts/tessdata/`.

## Деплой (один раз, ~5 минут)

1. **Репозиторий на GitHub**: создать **публичный** репозиторий и запушить:
   ```
   git remote add origin https://github.com/<user>/archero2Dashboard.git
   git push -u origin main
   ```
   (в этом проекте remote уже указывает на `ZaytsevAndrei/archero2Dashboard`)

2. **Секрет токена** (рекомендуется): Settings → Secrets and variables → Actions →
   *New repository secret* → имя `TG_BOT_TOKEN`, значение — токен бота.
   Пока секрета нет, работает встроенный запутанный fallback-токен (только для MVP).

3. **Первый запуск**: вкладка Actions → *Telegram poll & publish* → *Run workflow*.
   Workflow сам включит GitHub Pages (ветка `main`, папка `/docs`).

4. **Сайт**: `https://<user>.github.io/archero2Dashboard/` — появится через 1–3 минуты.

Если Pages не включился автоматически: Settings → Pages → Source: *Deploy from a branch* →
`main` / `/docs`.

## Сброс демо-данных

В `docs/data.json` лежат демо-записи (`"demo": true`) для примера. На сайте их можно
скрыть кнопкой «Скрыть демо». Чтобы удалить совсем: убрать их из массива `entries`
и закоммитить.

## Структура

```
docs/            сайт (GitHub Pages): index.html, app.js, style.css, data.json, proofs/
scripts/poll.mjs логика бота: опрос Telegram, парсинг урона, пруфы, запись данных
.github/workflows/poll.yml   расписание + автокоммит + включение Pages
```

## Замечания для продакшена

- Токен в open-source: задайте секрет `TG_BOT_TOKEN` и перевыпустите токен у @BotFather
  (текущий был опубликован в переписке).
- `getUpdates` нельзя использовать одновременно с webhook — скрипт снимает webhook при
  конфликте.
- Лимит файла для пруфа — 20 МБ (ограничение Bot API).
- Видеопруфы хранятся как один JPEG-кадр, чтобы репозиторий не пух.
- Скриншоты-пруфы хранятся **7 дней** (включительно): с 8-го дня файл и ссылка в
  `data.json` удаляются автоматически (записи урона остаются). Чистка запускается при
  старте бота и раз в сутки; ручной запуск: `PRUNE_ONLY=1 node scripts/poll.mjs`.
