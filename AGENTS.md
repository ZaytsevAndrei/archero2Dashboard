# AGENTS.md — правила проекта archero2Dashboard

Календарь урона гильдии Unity (Archero 2): статик-сайт + Telegram-бот.

## Как устроен деплой (коротко)

- `docs/` — сайт: GitHub Pages обслуживает ветку `main`, папку `/docs`. Любой пуш в
  `main` пересобирает сайт сам — отдельного деплоя сайта нет.
- `scripts/` — код бота: непрерывно работает на VPS (systemd-сервис `archero-bot`,
  `BOT_LOOP=1`). После пуша изменений в `scripts/` код на VPS нужно обновить и
  перезапустить:
  ```
  runuser -u bot -- git -C /opt/archero2Dashboard pull
  systemctl restart archero-bot
  ```
- `docs/data.json` и `docs/proofs/` — данные: их коммитит и пушит сам бот, руками не трогаем.

## Правила агента

1. По умолчанию **не коммитить и не пушить** — код пушит владелец, данные коммитит бот.
   Коммитить самому только по явной просьбе пользователя.
2. **В конце каждой задачи обязательно дать статус деплоя** — отдельным разделом:
   - нужно ли пушить в git, и какие именно файлы изменились;
   - нужно ли обновлять прод: менялся ли `scripts/` (→ пуш + `git pull` на VPS +
     `systemctl restart archero-bot`) или только `docs/`/`README` (→ достаточно пуша);
   - если ничего не требуется — явно написать «деплой не нужен, пушить нечего».
   Формулировка короткая, конкретная, с готовыми командами.
3. Файлы бота менять аккуратно: `scripts/poll.mjs` крутится в одном экземпляре на VPS
   (getUpdates конфликтует при параллельном запуске). OCR правим только с прогоном
   регрессии по всем живым пруфам из `docs/data.json`.
